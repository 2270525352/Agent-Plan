# Codex App 自动化模式

## 适用条件

- 用户使用 Codex App automation。
- 需要定时检查多代理执行是否偏离。

## 默认策略

- 频率：每 30 分钟。
- 类型：审查和状态报告。
- 默认不执行实现。
- 有阻塞项时停止推进并报告。

## 自动化应检查

- 用户原话对齐。
- 任务文档一致性。
- 代理分工冲突。
- Codex 禁止范围。
- 硬编码风险。
- 接口契约偏离。
- 测试和验收缺口。
- 文档状态回写。
- git 状态和提交纪律。

## 输出要求

输出必须短而可执行：

```text
状态：
发现：
阻塞：
需要用户确认：
下一步：
```
