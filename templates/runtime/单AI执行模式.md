# 单 AI 执行模式

## 适用条件

- 用户没有 CCB。
- 只有一个 Claude、Codex 或其他 CLI 窗口。
- 仍然需要 Agent-Plan 文档树和防偏离流程。

## 执行规则

单 AI 必须按以下顺序工作：

1. 读取用户原话文档。
2. 读取 AI 可读需求文档。
3. 读取总需求、总架构、总设计、接口契约。
4. 读取总任务文档。
5. 选择一个未完成任务。
6. 检查该任务是否满足执行条件。
7. 如果是需求、架构、文档任务，按 Claude 规则执行。
8. 如果是代码任务，按 Codex 规则执行。
9. 如果是审查任务，按 Reviewer-Claude 或 OpenCode 规则执行。
10. 完成后运行验收命令。
11. 更新状态文档。
12. 检查 git status。
13. 按 Git 提交纪律准备提交。

## 停止条件

- 任务边界不清楚。
- 需求没有来源原话或确认文件。
- 需要修改禁止范围。
- 验收标准缺失。
- 发现用户原话与任务冲突。
