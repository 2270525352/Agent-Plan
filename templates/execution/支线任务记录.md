# 支线任务记录

## 文档用途

记录主线窗口派给 helper / subagent / reviewer / ask / CCB / 第二窗口的所有支线任务。支线任务不是新的需求解释者,它只能按合同协助主线完成局部工作。

## 总规则

- 只追加,不改写历史记录。
- 每个支线任务必须绑定一个父任务 ID。
- 未写合同不得派发支线。
- 支线输出在主线合流门禁通过前,只能算建议或草稿。
- 主线窗口拥有最终解释权、合流权、提交权和停止权。
- 命中 RED 时,父任务必须停止,写入 `../05-reviews/偏离用户原话报告.md` 或 `../01-requirements/开放问题.md`。

## 合流分级

| 等级 | 含义 | 主线动作 |
|---|---|---|
| GREEN | 完整、在范围内、可追溯、验收/测试通过、无新增假设 | 主线复核后可合流 |
| YELLOW | 有价值但不完整、有假设、缺测试、需主线补改 | 记录缺口,补齐后再合流 |
| RED | 改需求、越界、冲突、破坏契约、无法验证 | 停止父任务并报告 |
