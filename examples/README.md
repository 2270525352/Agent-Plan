# 样板示例

这里是一个**填好的** Agent-Plan 文档树,给你看「规划做扎实之后长什么样」。

- 项目:`local-todo-cli` —— 一个本地命令行待办工具(不联网、不用数据库、数据存一个本地 JSON)。
- 展示从**用户原话**一路追溯到**任务说明**的关键链:

```
local-todo-cli/docs/agent-plan/
  00-source/用户原话文档.md       ← 逐字原话(连"别整"这种口语都照抄),最高真相源
  00-source/禁止偏离事项.md       ← 从原话提炼的硬边界(不许数据库/联网)
  01-requirements/AI可读需求文档.md ← 大白话转成带 id/约束/验收的可执行需求,逐条追溯到原话
  02-architecture/架构图.md        ← 真实架构图 + 每个部分的职责
  03-tasks/总任务文档.md           ← 按阶段、颗粒化、带允许/禁止范围和验收命令
  04-execution/任务说明.md         ← 单窗口 AI 照着执行的那份
  05-reviews/自动模式门禁.md       ← 审查通过、放行进自动模式的样子
```

注意贯穿其中的可追溯链:`UW-0001`(原话)→ `EMP/FB`(强调/禁止)→ `REQ-0001/0002`(需求)→ 架构组件 → `T-P0-0001/0002`(任务)→ 任务说明。**任何一处偏离,都能拿原话来对。**

> 这只是示例,不是模板。空白模板在 [`../templates/`](../templates/)。真实项目里,这些文档由 AI 按 [`../SKILL.md`](../SKILL.md) 的流程从你的原话生成,再经审查门禁。
