# 总任务文档

## 文档规则

- 本文档是任务拆分总纲。
- `../04-execution/任务说明.md` 的任务必须从本文档拆出。
- 不能新增未在本文档出现的实施范围,除非先更新本文档并通过审查。
- 每个任务的颗粒度要足够细:执行步骤可逐条勾选,允许/禁止范围具体到文件或目录,验收可命令化。

## P0 任务

### T-P0-0001

任务 ID：T-P0-0001

阶段：P0

任务名称：任务存储(读写 todo.json)

来源需求：REQ-0002

输入文档：../01-requirements/AI可读需求文档.md、../00-source/禁止偏离事项.md

允许修改：src/store.js

禁止修改：src/cli.js、其它任何文件;不得新增依赖

执行步骤（颗粒化,可逐条勾选）：
- [ ] `load()`:读运行目录 `todo.json`,不存在或解析失败则返回 `[]`
- [ ] `save(list)`:把数组写回 `todo.json`(UTF-8,2 空格缩进)
- [ ] 不引入任何 db 或网络

完成标准：load/save 能正确往返;文件损坏时按空列表重建

验收命令：`node -e "const s=require('./src/store');s.save([{t:'x'}]);if(s.load()[0].t!=='x')process.exit(1)"`

测试命令：`node --test test/store.test.js`

交付物：src/store.js

执行反馈记录 ID：FB-（执行时填）

状态回写：未开始

停止条件：发现需要 db 或网络才能完成 → 停,写偏离报告(违反 FB-0001/FB-0002)

Git checkpoint：完成并验收后提交 `T-P0-0001 (Codex): 实现 todo.json 存储`

状态：未开始

### T-P0-0002

任务 ID：T-P0-0002

阶段：P0

任务名称：三个命令 add / list / del

来源需求：REQ-0001

输入文档：../01-requirements/AI可读需求文档.md

允许修改：src/cli.js

禁止修改：src/store.js(只调用,不改)、其它文件

依赖任务：T-P0-0001

执行步骤（颗粒化,可逐条勾选）：
- [ ] `add <文本>`:load → push → save,打印「已加 #N」
- [ ] `list`:load → 带编号(从 1)打印每条
- [ ] `del <编号>`:load → 按编号删 → save,越界报错不崩
- [ ] 不新增用户没要求的命令

完成标准：add 后 list 可见;del N 后该条消失、其余保留

验收命令：`node src/cli.js add 买菜 && node src/cli.js list && node src/cli.js del 1`

测试命令：`node --test test/cli.test.js`

交付物：src/cli.js

执行反馈记录 ID：FB-（执行时填）

状态回写：未开始

停止条件：需求出现歧义(如编号从 0 还是 1)→ 停,写开放问题

Git checkpoint：`T-P0-0002 (Codex): add/list/del 命令`

状态：未开始
