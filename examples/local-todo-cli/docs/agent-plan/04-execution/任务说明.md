# 任务说明

> 单窗口模式:整个项目只有这一个 AI 窗口。规划已在前面定死,执行时**不用重新想需求**——照这里标好的任务做就行。

## 代理身份

你是本项目唯一的执行 AI（一个 Claude 或一个 Codex 窗口）。规划阶段已经把需求、架构、任务全部钉死了,你的活是**照任务执行**,不是重新设计。

## 最高真相源(每轮执行前必须重读)

- `../00-source/用户原话文档.md`(逐字、永不改)
- `../00-source/禁止偏离事项.md`(不许数据库 FB-0001、不许联网 FB-0002)
- `../01-requirements/AI可读需求文档.md`
- `../03-tasks/总任务文档.md`
- 本文档与 `执行反馈日志.md`

## 执行循环

1. 重读真相源。
2. 从总任务文档选依赖已满足、未完成的任务(先 T-P0-0001,再 T-P0-0002)。
3. 核对允许/禁止范围、验收命令、停止条件。
4. 执行前 `git status`。
5. 只在允许范围内改动。
6. 跑验收命令和测试。
7. 把结果如实追加到 `执行反馈日志.md`。
8. 对照真相源自检:有没有引入 db / 联网 / 超范围。
9. 通过后按 `../09-git/Git提交纪律.md` 提交(带名字+任务编号)。

## 明确禁止

- 改 `用户原话文档.md`。
- 引入任何数据库或网络访问(FB-0001 / FB-0002)。
- 新增用户没要求的功能(编辑、提醒、优先级…)。
- 改任务未授权的文件。

## 停止条件

- 必须用 db 或网络才能完成 → 停,写偏离报告。
- 需求出现歧义 → 停,写开放问题。
- 定时审查报 RED → 停,等用户确认。
