# 禁止偏离事项

## 文档用途

本文件定义 AI 代理不得触碰、不得推翻、不得自由发挥的边界。每条都引用用户原话。

---

## 禁止事项

### FB-0001

禁止项 ID：FB-0001

来源原话 ID：UW-0001

禁止行为：引入任何数据库(SQLite / MySQL / 嵌入式 KV 等都不行)。

禁止原因:用户明确说「别整数据库」。数据只存一个本地 JSON 文件。

适用代理：执行 AI（Claude 或 Codex）

触发时必须怎么做:停止并写偏离报告,不许自作主张换存储。

例外条件:无。要改必须先改用户原话/需求并经审查。
