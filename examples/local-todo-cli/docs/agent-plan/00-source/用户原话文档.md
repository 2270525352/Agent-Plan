# 用户原话文档

## 为什么这份文档最关键

人和 AI 有代沟:你用大白话说,AI 的理解能跟你差很远。所有后续文档只要跑偏了,就拿这份文档来对——它是判断「有没有偏离用户本意」的唯一锚。一旦原话被改写、润色、压缩,锚就歪了,后面全跟着歪。所以它必须**原封不动**。

## 文档规则

- 本文档是**最高真相源**。
- **逐字记录、只追加、永不修改**:不许改写、润色、删除、翻译、总结替代原话。AI 在任何情况下都不得编辑本文件。
- 如果需要 AI 可读的清洗版,另写 `../requirements/AI可读需求文档.md`,绝不在这里改原话。
- 每条记录必须保留用户原始表达,连错别字也照抄。

## 记录格式

```text
记录 ID：
时间：
来源：
上下文：
用户原话：
```
